# 學習系統產品與使用規格

版本：0.2.4
主要裝置：Samsung Galaxy Z Fold7  
資料模式：瀏覽器本機儲存  
內容語言：台灣繁體中文

## 1. 產品目的

學習系統用任務、反思、複習與能力證據協助使用者建立可實際運用的能力。AI 顧問養成是第一個學習範本；核心介面與進度引擎可沿用到其他學習主題。

## 2. 進入方式

### 瀏覽器

1. 開啟正式 GitHub Pages 網址。
2. 首頁載入目前啟用的學習範本。
3. 學習進度從目前瀏覽器的 `localStorage` 讀取。

### Fold7 主畫面

1. 用 Chrome 開啟正式網址。
2. 開啟瀏覽器選單，選擇「加到主畫面」或「安裝應用程式」。
3. 從主畫面開啟「學習系統」。
4. 已安裝版本使用 `manifest.webmanifest` 的 `start_url`，每次正式版本都必須帶有版本參數。

## 3. 首頁資訊

| 區域 | 顯示內容 | 資料來源 |
| --- | --- | --- |
| 顧問等級 | 等級、稱號、目前經驗值與下一級門檻 | 本機進度 |
| 學習摘要 | 累積分鐘、已完成任務數、有學習的日子、待複習項目 | 本機進度 |
| 今日路線 | 主線、支線、除錯與客戶情境任務 | 學習範本 |
| 能力地圖 | 六項能力與五級進度 | 範本初始值加上完成任務的能力證據 |
| 學習月曆 | 當月日期與實際學習日 | 本機學習時段 |
| 介面效果 | 動態效果的開關與目前偏好 | 本機瀏覽器偏好 |
| 本機資料說明 | 目前資料保存與隱私方式 | 固定說明 |

## 4. 任務操作

### 解鎖規則

- 沒有前置條件的任務可直接開啟。
- 尚未完成前置任務時，按鈕顯示「尚未解鎖」且不可操作。
- 完成前置任務後，相關任務立即解鎖。

### 開啟任務

點「開啟任務」後顯示：

- 任務類型、預估分鐘與經驗值
- 任務標題與說明
- 主教材閱讀索引、頁碼與閱讀深度
- 一題顧問應用反思
- 回答輸入欄與目前掌握程度
- 「完成任務」與「稍後再學」

### 內嵌原文閱讀

- Fold7 展開內螢幕以雙欄顯示：左側為任務與回答，右側為教材閱讀器。
- 閱讀器依任務的 `startPage` 開啟 PDF，並在標頭顯示完整指定頁碼區間。
- 教材來源是使用者本人可讀取的 Google Drive PDF。系統只在目前瀏覽器儲存該 PDF 的檔案識別碼，不會放進公開 Repository、範本或學習紀錄。
- 第一次閱讀時，在閱讀器內貼上 Google Drive PDF 共用連結並儲存。後續任務會直接載入對應頁面。
- 系統支援帶有 `#readingSource=<檔案識別碼>` 的一次性設定網址；fragment 不會送往 GitHub Pages 伺服器。來源寫入目前瀏覽器後，網址會立刻移除 fragment。
- 使用者必須在瀏覽器登入有權限讀取教材的 Google 帳號。若閱讀器無法載入，先確認 Drive 共用權限與登入帳號。
- 700 CSS px 以下將閱讀器排在任務內容後方，保留足夠閱讀高度；Fold 展開螢幕使用右側固定閱讀欄。

### 完成任務

按「完成任務」後：

1. 未輸入回答時顯示提示，不能完成任務。
2. 儲存原始回答與掌握程度。
3. 任務 ID 加入完成清單。
4. 增加任務經驗值與學習分鐘。
5. 依裝置本地日期寫入當天學習時段。
6. 更新等級、摘要、能力地圖與月曆。
7. 選擇「還不確定」時加入待複習；除錯與客戶情境任務也會加入待複習。
8. 同一任務不能重複獲得經驗值。

### 稍後再學

關閉任務視窗，不修改任何進度。

## 5. 學習反思

1. 點「記錄學習反思」。
2. 輸入不確定、有幫助或值得複習的內容。
3. 有內容時，系統寫入反思與待複習清單。
4. 取消或送出空白內容時，不修改資料。

## 6. 待複習清單

1. 點首頁摘要中的「待複習」開啟清單。
2. 清單會顯示任務名稱或學習反思、原始內容與加入日期。
3. 點「標記為已掌握」後，該項目從待複習清單移除。
4. 移除後首頁待複習數量立即更新。

## 7. 等級與能力計算

- 每 400 經驗值升一級。
- 稱號依序為：觀察者、需求拆解者、方案建構者、問題診斷者、解決方案架構師。
- 能力以五級呈現。
- 完成任務時，該任務標記的能力各增加一級，最高五級。

## 8. 學習月曆

- 週次從星期一開始。
- 顯示使用者目前所在月份。
- 完成任務的日期顯示為有色日期。
- 當天日期使用外框標示。
- 月曆只呈現實際學習，不因提醒或開啟網站自動填色。

## 9. 本機資料與重設

- 儲存鍵值為 `learning-os:ai-consultant:v1`。
- 資料包含經驗值、分鐘、完成任務、學習時段、回答、反思與待複習項目。
- 點右上角重設按鈕後，必須先顯示確認視窗。
- 使用者確認後才清除本機學習資料並重繪首頁。
- 不同瀏覽器或裝置的資料目前不會同步。

## 10. 語言與教材術語

- 所有介面與學習內容使用台灣繁體中文。
- 英文原文只在主教材採用「中文名詞（English Term）」格式時保留。
- 新增術語前必須先核對 PDF，不能自行補寫英文全名、縮寫或翻譯。
- 詳細規則以 `docs/LANGUAGE_POLICY.md` 為準。

## 11. PWA、離線與更新

- 首次上線時預先快取首頁、樣式、程式、manifest 與學習範本。
- 導覽請求採網路優先；離線時使用快取首頁。
- 靜態資源使用帶版本參數的網址，避免 GitHub Pages CDN 或舊 Service Worker 沿用前一版。
- 新版本必須同步更新 `package.json`、HTML meta、資源網址、manifest、Service Worker cache 名稱與範本版本。
- Service Worker 啟用後刪除舊版 cache。
- Service Worker 使用 `skipWaiting` 立即接管，註冊時停用舊 HTTP cache。
- 畫面頁尾顯示目前產品版本。

## 12. Fold7 響應式規格

- 700 CSS px 以下使用單欄任務與能力／月曆排列。
- 701 至 900 CSS px 使用雙欄任務，讓 Fold 展開畫面保持適合閱讀的卡片寬度。
- 外螢幕寬度需保留至少 16 px 邊距，所有主要按鈕不得橫向溢出。
- 展開螢幕使用較寬版面，但保留觸控友善的按鈕與對話框。
- 需要電腦的未來任務必須在任務卡與內容頁提前標示。

## 13. v0.2.x 已知限制

- 本機資料尚未跨裝置同步。
- 待複習目前支援查看與標記已掌握，尚未支援排程、編輯與重新作答。
- 反思目前可新增並從待複習清單查看，尚未支援編輯與匯出。
- 教材 Drive 連結只保留在設定過的瀏覽器；更換裝置或清除瀏覽器資料後需要重新貼上一次。
- 自動化課程評語仍由 ChatGPT 互動教學負責，靜態網站只保存自我回答與掌握程度。

## 14. 視覺與動態規格

- 使用台灣繁中系統字體優先順序：`PingFang TC`、`Noto Sans TC`、`Microsoft JhengHei`。
- 深色介面使用單一色彩系統：薄荷綠代表可執行與成長、金色代表經驗與閱讀、珊瑚色代表除錯、紫色代表自由探索。
- 主線、支線、除錯與客戶情境任務必須使用一致的標籤、色彩與卡片裝飾，讓類型可一眼辨識。
- 所有主要觸控按鈕最小高度為 44 CSS px，鍵盤焦點使用清楚的金色外框。
- 入場、進度與今日日期可使用短暫微動態；系統啟用「減少動態效果」時必須自動停用。
- 右上角「效果：開／關」可覆寫目前瀏覽器的動態偏好，設定只保留在本機。

## 15. 發布完成條件

每次發布必須同時符合：

1. `npm test` 通過。
2. GitHub Pages workflow 成功。
3. 正式網址回傳 200。
4. 正式頁面語言為 `zh-Hant-TW`，版本與預期相符。
5. 在窄版與展開版視窗完成核心互動回歸測試。
6. `docs/QA_CHECKLIST.md` 記錄測試版本、日期與結果。
