# 語言與術語規範

## 預設語言

所有使用者介面、課程、題目、回饋、閱讀說明與專案文件使用自然的台灣繁體中文。

程式欄位、檔案路徑、API 名稱、正式產品名稱與無適當中文譯名的技術識別字可保留原文。

## 英文術語規則

英文原文只能在主教材本身以「中文名詞（English Term）」形式呈現時加入。內容製作者必須先確認教材原文，不能依常見譯法自行補上英文。

允許的格式：

```text
中文名詞（English Term）
```

不得使用下列作法：

- 把整段課程翻成英文。
- 只顯示英文術語，卻省略教材使用的中文名稱。
- 未確認教材就自行補上英文縮寫、全名或翻譯。
- 為了看起來專業而在標題與按鈕混入英文。

## 範本要求

每個 `template.json` 必須設定：

```json
{
  "locale": "zh-Hant-TW",
  "languagePolicy": {
    "contentLanguage": "台灣繁體中文",
    "termRule": "英文原文只在教材以中文名詞加括號原文呈現時保留，格式為中文名詞（English Term）。",
    "autoTranslateTerms": false,
    "requiresSourceVerification": true
  }
}
```

新增或修改課程時，先確認繁體中文內容完整，再依 PDF 原文索引補上經確認的括號原文。
